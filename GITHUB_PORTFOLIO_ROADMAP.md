# Portfolio Navigation

The public profile emphasizes three existing repositories with distinct purposes.

| Repository | Focus | Current boundary |
| --- | --- | --- |
| [RNN Volatility Lab](https://github.com/SRG-eddieliu/rnn-volatility-lab) | Volatility forecasting and model diagnostics | Historical comparisons require benchmark correction and reevaluation |
| [OptionPricer](https://github.com/SRG-eddieliu/OptionPricer) | C++ derivatives pricing and numerical methods | Worked examples exist; a comprehensive numerical test suite is planned |
| [Systematic Alpha Lab](https://github.com/SRG-eddieliu/systematic-alpha-lab) | Financial data, factor diagnostics, and signal combination | Synthetic workflow; portfolio/risk/backtest/agent layers remain planned |

Earlier QuantLab component repositories are retained as standalone development history. Learning exercises are separate from the selected research and engineering work.

Additional research should be featured only when its implementation, personal contribution, data rights, evaluation, and reproducible entry point are clear. A report or planned repository alone is not presented as a runnable project.

This document replaces the earlier proposed six-repository roadmap. It is a navigation guide, not a record of validated investment results.
